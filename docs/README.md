# PDF Intake documentation

This directory contains durable product and engineering documentation for PDF Intake.

## Current documents

- [`architecture.md`](architecture.md) — current implemented architecture, approved interaction and domain decisions, safety boundaries, and lightweight decision history.
- [`roadmap.md`](roadmap.md) — planned product and engineering directions, deferred work, and explicit non-goals.

## Documentation rule

When implementation changes an approved product, interaction, architecture, or safety contract, update `architecture.md`.

When a newly discovered issue or desired improvement is not yet implemented, put it in `roadmap.md` rather than presenting it as current behavior.

Keep this documentation focused on durable repository-level product and engineering truth rather than active implementation or review status.
